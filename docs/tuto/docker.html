Installation sur NAS UGREEN (UGOS Pro) avec Docker

Installer Bêta home sur Docker

Du NAS éteint aux tablettes allumées : serveur, caméras, notifications, accès à distance, mises à jour.
Compter environ 30 minutes pour le serveur, puis 10 minutes par tablette.
Valable aussi pour Synology, un Raspberry Pi ou un PC Linux : seules les étapes « UGOS » changent.
Les libellés des menus UGOS peuvent varier légèrement selon la version du NAS.

Seul beta-home est indispensable. Tous les autres services sont commentés (désactivés) dans le fichier : vous les activez quand vous en avez besoin, un par un.

Ce qu'il faut avant de commencer

  • Le NAS UGREEN allumé, sur le réseau, avec UGOS Pro à jour.
  • L'application Docker installée depuis le Centre d'applications d'UGOS.
  • L'adresse IP du NAS (UGOS › Panneau de configuration › Réseau), par exemple 192.168.1.20. Idéalement, réservez-la dans l'application Deco (Plus › Avancé › Réservation d'adresse) pour qu'elle ne change jamais.
  • Le fichier beta-home-v7.17.zip (ou une copie du dépôt GitHub).
  • Une longue phrase secrète pour la clé du serveur, par exemple tram-cigogne-bretzel-2026-violet.

1Copier Bêta home sur le NAS

  1. Dans UGOS, ouvrez Fichiers et créez le dossier partagé docker (s'il n'existe pas), puis le sous-dossier beta-home.
  2. Décompressez beta-home-v7.17.zip sur l'ordinateur et copiez tout son contenu dans docker/beta-home.
  3. Vous devez obtenir :
docker/beta-home/
├── index.html, css/, js/, assets/      ← l'application
├── bridge/                              ← pont Alexa / app Maison (facultatif)
└── server/
    ├── docker-compose.yml                  ← le fichier à modifier
    ├── Dockerfile
    ├── mosquitto/mosquitto.conf
    ├── tailscale/serve.json
    └── data/                            ← créé au premier démarrage : TOUTES vos données
Le dossier server/data contient vos réglages, sauvegardes, codes et appairages. Ne le supprimez jamais, et ne le remplacez pas lors d'une mise à jour.

2Personnaliser le fichier docker-compose.yml

Ouvrez server/docker-compose.yml avec l'éditeur de texte d'UGOS (ou sur l'ordinateur). Seules ces lignes du service beta-home sont à changer :

services:
  beta-home:
    image: ghcr.io/ukiyo2208/beta-home:latest
    build:
      context: ..
      dockerfile: server/Dockerfile
    container_name: beta-home
    restart: unless-stopped
    network_mode: host                      # indispensable (découverte des caméras, Bonjour, HomeKit)
    environment:
      - PORT=8090
      - BETA_KEY=tram-cigogne-bretzel-2026-violet   # VOTRE phrase secrète
      - BACKUP_KEEP=30
      - GO2RTC_URL=http://127.0.0.1:1984
      - TZ=Europe/Paris                       # heures justes pour les règles, le réveil…
    volumes:
      - ./data:/data
RéglageRôle
BETA_KEYClé maîtresse du serveur. Elle protège tout l'accès. Gardez-la secrète : les écrans s'associent ensuite par QR code sans la recopier.
TZFuseau horaire. Sans lui, le NAS est en UTC et les règles se déclenchent 1 à 2 h trop tôt.
BACKUP_KEEPNombre de sauvegardes de la nuit conservées.
BETA_OFF (facultatif)Couper des modules serveur, par exemple BETA_OFF=famille,extra. Le reste fonctionne normalement.
PHOTO_DIR (facultatif)Dossier des photos pour le cadre photo des tablettes (avec le volume /photos, voir étape 8).
Image prête ou construction locale ? La ligne image: télécharge l'image construite par GitHub. Si le téléchargement est refusé (image pas encore publiée ou privée), supprimez la ligne image: : Docker construit alors Bêta home sur le NAS à partir des fichiers copiés (1 à 2 minutes, rien à installer).

3Créer le projet dans Docker (UGOS)

  1. Ouvrez l'application Docker › Projet › Créer.
  2. Nom du projet : beta-home.
  3. Chemin de stockage : choisissez le dossier docker/beta-home/server (celui qui contient docker-compose.yml). UGOS propose alors d'utiliser le fichier existant.
  4. Vérifiez le contenu affiché (vos modifications de l'étape 2), puis Déployer / Créer.
  5. Attendez que le conteneur beta-home soit « En cours d'exécution » (et go2rtc, mosquitto).

Alternative : en SSH (plus rapide si vous avez l'habitude)

Activez SSH dans UGOS (Panneau de configuration › Terminal), puis depuis l'ordinateur :

ssh votre-compte@192.168.1.20
cd /volume1/docker/beta-home/server        # adaptez « volume1 » si vos données sont sur un autre volume
sudo docker compose up -d                  # télécharge (ou construit) et démarre
sudo docker compose ps                     # état des services
sudo docker logs -f beta-home              # journal en direct (Ctrl+C pour quitter)

Dans le journal, vous devez voir une ligne du type Serveur Bêta 7.17 sur http://0.0.0.0:8090 — ….

4Premier accès et diagnostic

  1. Sur l'ordinateur, ouvrez http://192.168.1.20:8090 (l'IP de votre NAS).
  2. Suivez l'assistant d'accueil (prénoms, ville : Fegersheim).
  3. Réglages › Maison › Connexions › Serveur Bêta : adresse http://192.168.1.20:8090 et la clé BETA_KEY. Le voyant passe au vert.
  4. Ouvrez la page Installation et cliquez sur Relancer.
Ordinateur = écran comme les autres Une fois connecté avec la clé, utilisez « Associer cet écran (et oublier la clé) » dans Réglages › Sécurité : la clé n'est plus stockée dans le navigateur.

5Activer les services facultatifs

Dans docker-compose.yml, chaque service facultatif est précédé de #. Pour l'activer, retirez le # et un espace au début de chacune de ses lignes (l'indentation doit rester alignée), puis redéployez le projet (UGOS : Projet › beta-home › Recréer ; SSH : sudo docker compose up -d).

6Accès depuis l'extérieur avec Tailscale

Tailscale (gratuit) relie vos iPhone au NAS par un tunnel chiffré : aucun port à ouvrir sur la Bbox, et une adresse https (nécessaire au micro et à certaines applications).

  1. Créez un compte sur tailscale.com.
  2. Console d'administration › DNS : activez MagicDNS et HTTPS Certificates.
  3. Settings › Keys › Generate auth key : copiez la clé tskey-auth-….
  4. Dans docker-compose.yml, activez le service tailscale et collez la clé dans TS_AUTHKEY=. Redéployez.
  5. Installez l'application Tailscale sur chaque iPhone, connectée au même compte.
  6. Bêta home est joignable partout à https://beta-home.<votre-tailnet>.ts.net. Mettez cette adresse dans Connexions sur les iPhone, et dans OwnTracks.
OwnTracks (positions de la famille) : installez l'app OwnTracks, puis sur l'iPhone ouvrez la page Carte de Bêta home : le bouton Ouvrir dans OwnTracks configure l'app automatiquement (adresse …/api/owntracks, identifiant et mot de passe personnels).

7Mises à jour automatiques (Watchtower)

  1. Choisissez une deuxième phrase secrète, différente de BETA_KEY.
  2. Service beta-home : décommentez WATCHTOWER_TOKEN= et mettez cette phrase.
  3. Activez le service watchtower et mettez la même phrase dans WATCHTOWER_HTTP_API_TOKEN=. Redéployez.
  4. Dans Réglages › Système › Mises à jour, le bouton Mettre à jour télécharge la nouvelle image et redémarre Bêta home (environ 1 minute).

Sans Watchtower (manuel)

cd /volume1/docker/beta-home/server
sudo docker compose pull          # nouvelle image (ou : copiez les nouveaux fichiers puis « docker compose build »)
sudo docker compose up -d         # redémarre seulement ce qui a changé ; server/data est conservé
Mise à jour en copiant un nouveau zip Remplacez tout sauf le dossier server/data et votre docker-compose.yml personnalisé.

8Sauvegardes et photos

Copie des sauvegardes sur une clé USB

Branchez une clé USB sur le NAS, repérez son chemin dans Fichiers, puis décommentez la ligne de volume /backup du service beta-home :

    volumes:
      - ./data:/data
      - /mnt/@usb/sdb1/beta-backup:/backup    # adaptez le chemin de votre clé

Puis dans Réglages › Système › Sauvegarde : mot de passe de sauvegarde (notez-le !), sauvegarde de la nuit, copie vers /backup.

Cadre photo des tablettes

      - /volume1/Photos:/photos:ro             # lecture seule

Puis Réglages › Écrans et iPhone › Cadre photo : dossier /photos (ou l'adresse de votre serveur Immich).

9Les tablettes Fire avec Fully Kiosk

  1. Sur la tablette : Paramètres › Sécurité et confidentialité › Applications de sources inconnues : autorisez le navigateur Silk.
  2. Dans Silk, téléchargez Fully Kiosk Browser depuis le site officiel fully-kiosk.com et installez-le.
  3. Dans Fully Kiosk › Settings › Web Content Settings › Start URL : http://192.168.1.20:8090.
  4. Device Management : Keep Screen On activé ; Remote Administration activé avec un mot de passe (Bêta home l'utilise pour allumer l'écran, régler la luminosité et parler).
  5. Web Content Settings : autorisez micro et caméra si vous utilisez l'interphone ou la commande vocale « Bêta ».
  6. Sur l'ordinateur : Réglages › Sécurité › Associer un nouvel écran, puis scannez le QR code avec la tablette (ou tapez le code affiché).
  7. Sur la tablette : Réglages › Écrans et iPhone › Cet écran : nom (« Cuisine », « Salon », « Étage »), veille, page de départ.
  8. Dans Marques › Fully Kiosk, ajoutez la tablette (IP + mot de passe Remote Administration).
Performance Les tablettes Fire passent automatiquement en mode performance (moins d'effets). Bêta home est livré en un seul fichier compressé : le premier chargement est rapide, même en Wi-Fi moyen.

10Les iPhone et les notifications

  1. Safari › adresse de Bêta home › Partager › Sur l'écran d'accueil.
  2. Associez l'iPhone comme une tablette (QR code) : il ouvre directement la page « Raccourcis ».
  3. Installez l'application ntfy (App Store) et abonnez-vous au sujet indiqué dans Réglages › Famille › Notifications.
  4. Bouton Tester : la notification doit arriver en quelques secondes.
  5. Siri : Réglages › Écrans et iPhone › iPhone : Siri et widgets pour ajouter « Je pars », « Je rentre », « Bonne nuit ».

11Sécuriser

  • BETA_KEY longue et unique (jamais « changez-moi… »). Le diagnostic le vérifie.
  • Un code PIN pour chaque parent, puis Mode sécurisé dans Réglages › Sécurité.
  • Les écrans associés par QR, puis « oublier la clé » sur l'ordinateur.
  • Aucun port ouvert sur la Bbox : passez par Tailscale pour l'extérieur.
  • Mot de passe de sauvegarde noté sur papier, sauvegarde de la nuit activée.
  • Mosquitto : pour exiger un mot de passe, suivez les deux lignes d'explication en tête de server/mosquitto/mosquitto.conf.
Bon à savoir Après 30 essais de clé ou de code erronés en 10 minutes, le serveur bloque l'adresse concernée quelques minutes. Les mots de passe (box, Deco, e-mail…) restent sur le NAS, dans server/data, lisibles par lui seul.
